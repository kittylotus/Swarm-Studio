# Standalone Studio 0.63.21 | Editing UI pass 2

Cumulative overlay on Atelier transplant 1. All previous prompt, expression, despill, processing, Library and Easel improvements retained. Package and Tauri versions unchanged.

## Changes
- Rename visible workspace labels to Editing (internal `editor` routing preserved). Use the existing Studio theme, typography, control radii and accent surfaces. Compact grouped icon tool rail, canvas background, tool property inspector, selection action strip and small inline edge controls. Mobile rail moves under the canvas and inspector scrolls independently.
- Keyboard shortcuts: H pan, W wand, L lasso, R rectangle, B brush, E eraser, Q Liquify, C crop, D despill, I Inpaint, U upscale, G background removal; Ctrl/Cmd+Z pixel undo; Ctrl/Cmd+Shift+Z or Y pixel redo; Ctrl/Cmd+Alt+Z selection undo; Ctrl/Cmd+Alt+Shift+Z selection redo; Ctrl/Cmd+A select all; Ctrl/Cmd+D or Esc deselect; Ctrl/Cmd+Shift+I invert; Delete clear selection; brackets adjust brush; 0 fit, +/− zoom; Ctrl/Cmd+S export PNG. `?` or the header help icon opens the shortcut guide. Shortcuts are workspace scoped, do not override typing in input fields, and respect busy/dialog states.
- Inpaint: canvas-first layout, Mask/Prompt inspector tabs with no canvas remount on tab or tool switch, one Generate edit action, compact mask operations. Native generation settings and processing remain intact. Inpaint shortcuts B/E/R/L/H, brackets, Ctrl/Cmd+Z and redo, 0 fit, Ctrl/Cmd+Enter generate, Esc back to Editing, ? help. Existing GPU generation preview fills the canvas stage.
- Result review overlays the entire Inpaint layout. Desktop Before/After side by side; narrow workspace Before/After tabs. Persistent decision footer. The underlying mask and settings controls are inert during review. Discard preserves source, mask and prompts (the already indexed output remains in Library). Use edit applies the result to the original working document and leaves pixel undo available. Pending review blocks replacing the source or exiting the mask session via Back. Suppress redundant completion toast while Editing is visible; any other review-time toast is positioned away from the decision footer.
- Fixed GPU recipe-field insertion against the new button class. Existing custom JSON/built-in workflow selection and Keep final only controls retained.
