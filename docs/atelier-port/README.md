# Standalone Studio 0.63.21 | Atelier transplant 1

Source-only cumulative overlay, based on the supplied standalone 0.63.21 source and LumiSwarm 1.1.0-alpha.9.4. Package and Tauri versions are deliberately unchanged. No Cast Recipe, Genesis, Visual Lore, Spindle, RP protocols, new storage architecture or presentation-library replacement.

## Changes
- Editor: persistent pixel document and themed canvas; hand/zoom, wand/lasso/rectangle, selection modes and independent selection history, clear to alpha, brush/eraser, Liquify, despill, crop/rotate/flip, undo/redo, PNG export. Generate remains in Create only. Existing GPU processing recipes retained. Inpaint is opened explicitly and carries working pixels and selection; accepted results return to the same canvas. Rejection retains the native mask editor. GPU results use the existing library/replacement review lifecycle.
- Editing limits: max 16 megapixels, max side 8192, upload max 50 MB, PNG/JPEG/WebP. Pixel history limited to 16 entries and approximately 96 MiB, selection history to 12 entries and approximately 32 MiB. Geometry-changing operations reset selection history. Local tools operate in memory. PNG export is explicit; local edits do not overwrite or automatically create Library entries. GPU outputs retain native Library registration. The working document is not a new durable project format. Brush/eraser/Liquify are free painting; selection limits clear/despill, crop and Inpaint mask transfer.
- Prompt enhancer: provider-first model detection; updated authoring guidance, Anima Aesthetic mode, tag qualifier escaping and optional explicit count reinforcement on Apply (Anima, Illustrious). Existing custom guidance, MOSS JSON, reference adapters, LoRAs and manual prompt entry are retained. No regional transport changes or new RP compiler.
- Expressions: shared character, outfit, temperament and rendering prompt fields; model-aware style handling and shared Anima adapter prompt assembly. Existing project schema is backwards compatible. Optional green/blue despill at 70% after successful background removal. Raw output retained if local despill fails; project-local cleaned image does not falsely point to the remote raw image. Re-run cutout or use Editor despill if local cleanup fails. Existing final-only policy controls intermediate project takes. External Swarm files remain governed by native retention/review.
- Easel: themed background, clamped restored position, cancelled pointer handling, preview sizing. This is targeted polish, not a full redesign.

## Install
Back up the existing source checkout. Extract this ZIP over the checkout root (same relative paths), preserving Projects, local config, user output and node_modules. Do not replace the entire directory or delete Projects. Run the existing startup procedure or `npm run check` and `npm run build` with dependencies installed. No dist or packaged executable supplied.
