# Swarm Studio v0.48.0

## Changed
- Right-clicking any Library card now enters batch-selection mode at that card and immediately exposes the sticky bottom action rail.
- The generation mini-monitor now appears only when a generation is active and you navigate away from Create. Create keeps using its full built-in generation preview without the redundant floating monitor.
- Appearance copy now describes the mini-monitor's leave-Create behavior.
