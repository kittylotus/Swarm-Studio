# v0.29 — desktop LoRA grid + non-matching metadata pass

- Promotes the installed-LoRA List/Grid density toggle to desktop as well as mobile.
- Grid mode uses thumbnail-forward cards with Add/Added and metadata editing pinned to the card footer.
- Adds a persisted **Show non-matching** control to the Models LoRA library.
- When enabled, Studio exposes the entire Swarm LoRA inventory so misclassified/incompatible models can still be opened in the metadata editor and repaired.
- Create/Tune composer selection remains compatibility-filtered; this affects browsing/metadata maintenance only.
