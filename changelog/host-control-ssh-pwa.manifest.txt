Safety boundary:
- Browser/PWA can request only fixed Swarm start/stop/restart/status verbs.
- No arbitrary command, executable, or argument surface is exposed to the browser.
- PWA control POSTs require the per-process HttpOnly SameSite session cookie and a same-origin Origin header.
- SSH Studio launch is brokered by an interactive Windows Scheduled Task installed explicitly by the user.
