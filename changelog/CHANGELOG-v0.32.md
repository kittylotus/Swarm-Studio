# Swarm Studio v0.32

## LoRA organizer

- Added collapsible Swarm-folder navigation for the LoRA library.
- Added batch selection beside the LoRA list/grid control.
- Added batch move-to-folder support using SwarmUI `RenameModel`, including typed nested destination paths.
- Refreshes model inventory after moves and opens the destination folder.
- Batch move failures are isolated per model and reported in Logs without discarding successful moves.
- Mobile LoRA grid now uses the same portrait-card treatment as desktop.
