# Swarm Studio v0.34

## LoRA hygiene and inspection

- Added persistent local CivitAI creator blocking from the model detail view, with a clear-blocks recovery control.
- Blocked creators are removed from CivitAI browse/search results.
- Preserved both desktop content scroll and mobile document scroll while the CivitAI install queue appears, updates, and disappears.
- LoRA library preview images now open a read-only rendered metadata card instead of forcing raw metadata editing.
- LoRA stack thumbnails open the same metadata card.
- Metadata cards expose readable description/usage text, triggers, tags, model facts, and a CivitAI post link when source metadata is available.
- Restored the Trigger toggle in the mobile Tune LoRA stack.
