# Swarm Studio v0.23

## CivitAI sticky-flow + final-row spacing

- CivitAI search/filter/pagination toolbar now participates in normal document flow and only sticks once it reaches the top of the scroll viewport.
- Removed the artificial sticky offset that left cards visibly scrolling through a gap above the toolbar.
- Added dedicated bottom breathing room to the CivitAI browser/grid so the final row Details/Install actions can always be scrolled fully clear of the viewport edge.
- Mobile keeps additional safe-area space for the fixed context bar.
