# Swarm Studio v0.25

## Mobile LoRA library density

- Added a persistent mobile List/Grid toggle to the installed LoRA library.
- Grid mode automatically fits two or three columns from the available viewport width rather than hard-coding one phone size.
- Compact grid cards promote the preview image and move Add/Added + metadata edit actions to a dedicated bottom row.
- List mode remains the default/fallback and can be restored with the same dynamic toggle.
- Search filtering continues to operate in-place in either layout.
